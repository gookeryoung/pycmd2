# Vue Todo 应用

这是一个基于Vue 3和Pinia的待办事项管理应用，提供了完整的待办事项管理功能。

## 功能特点

- ✅ 添加新的待办事项
- ✅ 标记待办事项为已完成/未完成
- ✅ 删除待办事项
- ✅ 批量清除已完成的待办事项
- ✅ 按状态过滤待办事项（全部/待完成/已完成）
- ✅ 实时统计和进度显示
- ✅ 响应式设计，支持移动端
- ✅ 优雅的动画效果

## 技术栈

- Vue 3 (Composition API)
- Pinia (状态管理)
- Element Plus (UI组件库)
- Vue Router (路由)

## 访问方式

应用已配置为独立路由，可通过以下URL访问：

```bash
/todo
```

```bash
todo/
```

## 状态管理

应用使用Pinia进行状态管理，store定义在 `src/stores/todos.ts` 中，包含以下功能：

- 状态管理（todos列表、过滤器、加载状态、错误信息）
- 计算属性（过滤后的todos、统计信息、完成百分比）
- 操作方法（添加、切换、删除、清除、获取todos）

## 使用说明

1. **添加待办事项**：在输入框中输入内容，按Enter或点击"添加"按钮
2. **标记完成**：点击待办事项前的复选框
3. **删除待办事项**：点击右侧的删除按钮（会弹出确认对话框）
4. **过滤显示**：使用顶部的过滤按钮按状态筛选
5. **清除已完成**：点击"清除已完成"按钮批量删除已完成的待办事项
6. **刷新列表**：点击"刷新"按钮重新加载待办事项

## 特色功能

- **本地存储**：所有待办事项自动保存在浏览器本地，刷新页面不会丢失数据
- **进度条显示**：实时显示待办事项完成进度
- **相对时间**：显示创建时间的相对时间（刚刚、几分钟前等）
- **动画效果**：列表项的添加和删除带有平滑过渡效果
- **响应式布局**：自动适应不同屏幕尺寸
- **确认对话框**：删除操作前会弹出确认对话框，防止误操作
- **示例数据**：空列表时可以点击"添加示例待办事项"快速体验功能
- **数据管理**：提供清除所有数据的功能，支持完全重置
